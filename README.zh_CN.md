# 围棋闯关 —— 三键设备上的围棋升级之路

一台三键手持设备上的离线围棋解谜闯关：**7 章 154 关**，从认识第一口气，到吃子手筋、
对杀收官，再到劫争。每一张棋盘、每一条正解路径、每一道题都装在设备里：
**不联网、不插卡、不配手机**。

关卡改编自网页版《围棋闯关》—— 那个游戏从 online-go.com 的 LearningHub 教程抽取而来。
设备版沿用它的章节阶梯与三星评分，关卡数据由派生它的网页游戏供给。

| 标题页 | 世界地图 | 对局 | 结算 |
| --- | --- | --- | --- |
| 大标题、三项菜单（继续闯关 / 音量 / 重置记录）与一行成绩。 | 青铜到王者七章，各章显示通关数，未解锁的灰显。 | 9x9 棋盘与金色光标，上方是题面与候选点标记。 | 星级、得分与走错次数，按一下确定就进下一关。 |

## 一局怎么玩

| 页面 | 屏上有什么 | 三个键 |
| --- | --- | --- |
| **标题** | 大标题、三项菜单与一行「通关 12/154 · ★30」 | 上下选择，确定进入。音量项按确定在六档（关 + 20%..100%）间循环；重置记录**按两次确定**才生效 |
| **世界地图** | 七个章节，全部可进；选中的章节在底栏提示里报进度 | 上下选择，确定进入章节，长按确定返回 |
| **关卡列表** | 一屏五行：序号、短标题（网页版「 · x/N」后缀已剥）、已得星级 | 上下移动，确定进入任意关卡，长按确定回地图 |
| **题面** | 本关说明（可滚动）；选择题先放小棋盘再放题干 | 上下滚动，确定开始，长按确定返回 |
| **作答** | 9x9 棋盘、金色光标、一行状态 | 上/下短按移一行，上/下**双击**移一列，确定落子（或确认 / 移死子），长按确定回题面 |
| **结算** | 至多三星、每星 100 分、走错次数 | 确定进下一关，长按确定回列表 |

判题与网页版一致：每一手必须延续本题正解路径中的某一条；合法但不属于任何路径的一手
记一次走错并复位棋盘。零错三星、一错两星、再错也保底一星。完整的围棋规则
（气、提子、禁自杀、简单劫）都在设备上运行。

## 里面装了什么

- **154 关**：落子解谜 119 关、选择题 32 关、终局教学 3 关，青铜 → 白银 → 黄金 →
  铂金 → 钻石 → 星耀 → 王者。网页版的 19x19 棋面按包围盒裁进 9x9 窗口，每条正解
  路径都在裁剪后的棋盘上用完整规则重新校验过 —— 原局面的 94% 都装得下。
- **纯逻辑内核**：规则引擎、闯关状态机、进度存档与中文折行都在宿主机上编译运行，
  所以 `tools/validate.sh` 会在刷机前**把每一关真打通一遍**、把每条正解路径逐手重放。
- **没有任何音频资产**：音效是实时合成的方波 RTTTL。网页版 2.8MB 的背景音乐
  在立项时就被明确放弃。
- **603 个码点的字库子集**，三档字号（16/24/32px），由 `tools/weiqi/gen_font.py`
  从 Noto Sans CJK SC 生成。

## 构建

这是 [ESP-IDF](https://github.com/espressif/esp-idf) 5.5.3 工程，目标板是 FoloToy AI
Passport（ESP32-C3，240x320 ST7789，三键 ADC 按键）。

```bash
idf.py build            # 编译固件
idf.py flash monitor    # 烧录并看日志
./tools/validate.sh     # 仓库门禁：文档、生成物、宿主测试、固件
```
