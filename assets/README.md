# Assets

Everything the firmware embeds beyond code. This app ships **fonts only** — there are no audio
assets (effects are RTTTL-synthesized at runtime, see `main/wq_sfx.c`) and no bitmap images
(the board is drawn from widgets, see `main/wq_ui.c`).

| File | What it is | Provenance |
| --- | --- | --- |
| [`fonts/charset.txt`](fonts/charset.txt) | The derived character inventory, one comment header plus the codepoints | Generated by `tools/weiqi/gen_font.py`; never edit |
| [`fonts/wq_font_16.c`](fonts/wq_font_16.c) | 16 px LVGL font subset | Generated; Noto Sans CJK SC, SIL OFL 1.1 |
| [`fonts/wq_font_24.c`](fonts/wq_font_24.c) | 24 px LVGL font subset | Generated; Noto Sans CJK SC, SIL OFL 1.1 |
| [`fonts/wq_font_32.c`](fonts/wq_font_32.c) | 32 px LVGL font subset | Generated; Noto Sans CJK SC, SIL OFL 1.1 |

## How the inventory is derived

`tools/weiqi/gen_font.py` unions three sources, so the fonts can never drift from either the
levels or the interface strings: the characters of every level (via `tools/weiqi/content.py`,
the same module `gen_content.py` uses), the non-ASCII characters of every string literal under
`main/` (comments stripped first), and a fixed base of printable ASCII plus the punctuation and
symbol set (star glyphs for ratings, board marks such as the triangle). Before converting, every
codepoint is checked against the master font's cmap — a missing glyph is a build failure, not a
hollow box on the device.

`gen_font.py --check` re-derives the inventory and re-parses the generated `.c` files (their
sparse cmap tables) to assert every codepoint is really present; `tools/validate.sh` runs it in
the static gate.

## The master font

Noto Sans CJK SC Regular, SHA-256
`2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`,
SIL Open Font License 1.1 — a licence that permits subsetting and redistribution inside the
firmware. See `tools/weiqi/gen_font.py` for the download URL and the conversion command.

## Level content

The level data itself is compiled into the firmware from `tools/weiqi/levels.txt` (the source of
truth) via `tools/weiqi/gen_content.py`. Its provenance — the AGPL-3.0 web game it was extracted
from, and the 9x9 cropping rule — is documented in the application record
[`docs/reference/liangdabiao/weiqi-quest/README.md`](../docs/reference/liangdabiao/weiqi-quest/README.md)
and in the header comment of `tools/weiqi/levels.txt`.
